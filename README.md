# VisualLearn - Creative Video Editor & Motion Designer Portfolio

A studio-grade, high-performance portfolio website built with semantic HTML5, Vanilla CSS3 glassmorphism design system, and custom JavaScript featuring a 300-frame scroll-driven canvas animation and five 3D Cover Flow showcase modal decks.

## ✨ Features
- **300-Frame Scroll Canvas Animation**: Smooth physics-lerped canvas animation that responds in real-time to scroll position.
- **GitHub-Optimized Assets Structure**: Frames arranged in subfolders (`frames-1`, `frames-2`, `frames-3`) adhering to GitHub's 100-file per upload limit.
- **5 Dedicated 3D Cover Flow Modals**:
  1. Motion Graphics Showcase
  2. Talking Head Masterclass Showcase
  3. Phonk Edits & Speed Ramps Showcase
  4. Real Estate Cinematic Showcase
  5. Cinematic Color Grade Showcase
- **Master Cinema Video Player**: 4K/60fps modal player with custom timeline scrub bar and audio controls.

## 🚀 How to Run Locally

```bash
# Start local streaming server
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
